# Medieval Simulator

A living medieval world of castles, villages and sieges that plays itself: three rival houses build fortresses, trade, forge alliances and lay siege, led by AI commanders.

**Play:** https://deakro-bit.github.io/deakro/

On a phone, open the link in Chrome and choose *Add to Home screen* to install it as an app (full screen, landscape, works offline after the first load).

Single-file WebGL game (three.js), © Deák Róbert 2026.
